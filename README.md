Сервис коротких ссылок

Описание:

Это приложение сокращает длинные ссылки, делает их удобными для использования и добавляет полезные функции:  
- Можно задать ограничение на количество переходов.  
- Ссылки автоматически удаляются через 24 часа.  
- Уведомления сообщают, если ссылка больше не работает.  
- Каждый пользователь получает свои уникальные ссылки.

Как пользоваться сервисом:
1. Создание короткой ссылки: 
   - Введите длинный URL, и сервис вернет уникальную короткую ссылку.
   - Каждая ссылка привязывается к UUID пользователя, который генерируется автоматически.
   
2. Переход по короткой ссылке:
   - Введите короткую ссылку в консоли, чтобы открыть ее в браузере.
   
3. Управление ссылками:
   - Лимит переходов задается пользователем при создании ссылки.
   - Ссылки автоматически удаляются после истечения времени жизни (по умолчанию 24 часа).

Команды:
- Создание короткой ссылки - 1: введите длинный URL.
- Переход по ссылке - 2: ведите короткую ссылку.
- Список ссылок - 3.
- Выход - 4: завершает работу/

Тестирование:
Проверьте следующие сценарии:
  - Создание короткой ссылки.
  - Исчерпание лимита переходов (лимит 5 ссылок).
  - Удаление устаревших ссылок.
  - Генерация уникальных ссылок для разных пользователей.
